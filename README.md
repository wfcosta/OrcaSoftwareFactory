# SoftwareFactory

Reusable software-factory workflows for coding agents. The first integration is
for **Orca**: it uses Orca's agent orchestration to dispatch specialist roles,
inspect their responses, and move work through explicit quality gates.

- [Orca Software Factory](orca-software-factory/README.md)
- Start with its [Orca orchestrator playbook](orca-software-factory/ORCA_FACTORY.md).

This is a set of portable prompts and workflow guidance, not an Orca plugin or
an undocumented Orca API. Agent creation, worktree selection, and response
inspection happen in Orca's UI using the controls available in your version.
